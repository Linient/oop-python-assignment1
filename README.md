# OOP with Python – Five Mini-Projects

Five small, tested Python projects set in a Ugandan context. Each one models its domain with classes, analyses the
results in a Jupyter notebook, and ends with a *Findings & Limitations* section.

| # | Notebook | Reusable code | Tests |
|---|---|---|---|
| 1 | `project1_population.ipynb` – UBOS district population forecaster | `src/population.py` | `tests/test_population.py` |
| 2 | `project2_microgrid.ipynb` – solar micro-grid dispatch planner | `src/microgrid.py` | `tests/test_microgrid.py` |
| 3 | `project3_fishery.ipynb` – Lake Victoria fish stock & export risk | `src/fishery.py` | `tests/test_fishery.py` |
| 4 | `project4_rainfall.ipynb` – rainfall & crop suitability | `src/rainfall.py` | `tests/test_rainfall.py` |
| 5 | `project5_taxi.ipynb` – taxi route revenue, pricing & fleet | `src/taxi.py` | `tests/test_taxi.py` |

`src/metrics.py` holds the error measures (MAE, RMSE, MAPE) shared by projects 1 and 5.

## Setup

Python 3.10 or newer is required.

```bash
# 1. Get the code
git clone git remote add origin https://github.com/Linient/oop-python-assignment1.git
cd python-oop-assignment

# 2. (Recommended) create a virtual environment - a private box of libraries for this project
python -m venv .venv
.venv\Scripts\activate          # Windows

# 3. Install the libraries
pip install -r requirements.txt
```

## How to run

   - start Jupyter from the project folder using command 'jupyter notebook', open a notebook and choose "Kernel → Restart & Run All".

   **Tests:**

   - use command "python -m pytest"


All 48 tests pass, and every notebook runs top to bottom without errors. Random numbers use fixed seeds
(`np.random.default_rng(seed)`), so the results are the same on every run.

## Summary of findings

1. **Population.** The exponential (CAGR) model beat the linear trend in every district (test MAPE under 2.1%). The
   Fibonacci-ratio model was 78–92% wrong. Wakiso grows fastest (6.5% a year) and needs the most new classrooms by
   2029 (about 2,090), more than Kampala, although it is smaller today.
2. **Micro-grid.** The system is well-conditioned (determinant −5, condition number 5.8), but 4 of 30 simulated days
   could not be met without negative battery energy. Non-negative least squares gave the closest feasible plan and
   the shortfall in kWh. The battery is the more volatile and more sensitive source. Monthly energy cost is about
   UGX 341,000.
3. **Fish stock.** h = 0.10 is sustainable (stock settles at 7,500 t). Catch peaks at h = 0.20, which is the MSY of
   1,000 t a week. h = 0.30 is overfishing: the same catch as h = 0.10 from a third of the stock. The raw
   "variance > 50,000" risk rule is meaningless (the units are UGX²), so risk is classified by the coefficient of
   variation instead. The 5% VaR is about 17% below average annual revenue.
4. **Rainfall.** Cosine similarity calls all regions similar, but Pearson correlation shows their seasons are out of
   step. Gulu has one long growing window, and Mbarara has two short ones suited to beans. Real NASA data shows Kampala
   is clearly bimodal (April and November peaks) and that the illustrative data badly overstates January–February rain.
5. **Taxi.** The Ntinda fare (UGX 2,000) is below equilibrium (UGX 2,200), which creates a shortage. The best
   forecaster was "tomorrow = today" (exponential smoothing with α = 1). One vehicle per route covers day 11. With a
   weekly pattern, a seasonal-naive forecaster beats the moving average by a factor of 3.5.

Each notebook's *Findings & Limitations* section has the full discussion.
